# LeLamp/OpenClaw 投影硬件方案对比

结论：MVP 和首代可落地产线推荐“底座投影”。“球形结构内置投影”保留为 ID 概念验证或高端版本探索，不进入首代主线。

推荐理由不是外观偏好，而是办公投影的真实约束：亮度、热、噪音、光机体积、镜头角度、散热风道、维护、成本和重心。公开投影资料显示，中高环境光办公室需要远高于普通微投的亮度；把光机塞进球形灯头会同时放大亮度不足、热堆积、结构重量和运动稳定性问题。

## 1. 设计假设

产品定位：
- 桌面本地 AI 工作终端，不是会议室主投影仪。
- 投影优先用于会议行动项确认、倒计时、摘要卡片、文档要点和授权提示。
- 首代目标是 20-40 英寸近距离可读卡片；明亮会议室大屏展示可通过外接显示/会议室投影实现。

环境假设：
- 桌面办公：用户距离 0.5-1.5 米，投影到桌面、近墙、白板或小幕布。
- 小会议室：2-6 人，环境光可局部控制。
- 明亮会议室/有窗会议室：首代不承诺替代主投影。

证据约束：
- Epson 指出有窗会议室/教室建议至少约 2500 lumens。
- XGIMI 的投影指南将中环境光对应约 600-1600 ANSI lumens，高环境光对应约 1600-2500 ANSI lumens。

## 2. 关键硬件需求

| 需求 | MVP 下限 | 产品化目标 | 验证方式 |
| --- | --- | --- | --- |
| 投影亮度 | 暗/低光桌面卡片可读 | 中等环境光下 20-40 英寸卡片可读 | 300/600/1000 ANSI 样机 A/B 测试 |
| 分辨率 | 720p 可读文字 | 1080p 优先 | 10pt/12pt 中文卡片可读性 |
| 投影距离 | 0.4-1.5 米 | 支持桌面和近墙 | 投射比、梯形校正、自动对焦 |
| 散热 | 连续 20 分钟不降亮 | 60 分钟会议稳定 | 热像仪、风扇噪音、降频日志 |
| 噪音 | 不干扰 ASR | 会议模式低于可感知阈值 | 麦克风旁噪音与 ASR 误差测试 |
| 摄像头 | 能看桌面文档 | 兼顾人、纸、投影面 | 多角度覆盖率测试 |
| 麦克风 | 单人/近场可用 | 2-6 人会议可用 | 会议样本 WER/说话人分离 |
| 成本 | 不破坏开发样机 | 有 BOM 分层 | 光机、散热、结构、算力分项 |

## 3. 方案 A：球形结构内置投影

定义：
- 将 DLP/LCOS 光机、镜头、散热和部分传感器放入灯头或球形头部。
- 投影方向跟随头部姿态，形成“看向哪里、投到哪里”的交互感。

优势：
- ID 统一，产品第一眼更像“AI 具身终端”，而不是普通底座加投影仪。
- 投影方向和灯头朝向一致，适合人物化交互和局部指示。
- 可让摄像头、投影和状态灯共享头部注意力语义。

主要代价：
- 亮度受限：球形头部体积有限，光机、LED/激光、散热器和风道空间不足。
- 热风险高：投影光源和算力靠近摄像头/麦克风/舵机，长会议会引入热噪声、降亮和结构寿命问题。
- 噪音风险高：小风扇在头部靠近麦克风，容易污染会议录音。
- 重心变差：头部增加光机和散热后，舵机负载、晃动、寿命和定位精度都会受影响。
- 线缆复杂：视频、供电、传感器、舵机信号穿过转动关节，可靠性和装配难度上升。
- 镜头开孔破坏形态：球面要留光路窗口、散热孔、摄像头孔和麦克风孔，防尘、防眩光和可维护性变差。
- 成本不可控：定制光机、散热、镜头和结构件都可能推高首代 BOM。

适用条件：
- 投影只做小面积图标、状态、箭头或 10-20 英寸低光卡片。
- 可接受头部不频繁运动，或投影时头部锁定。
- 有能力做定制光机、热仿真、低噪风道和结构可靠性测试。

不适合首代的原因：
- 办公场景需要文字可读，亮度与热稳定优先级高于“投影藏在头部”的惊艳感。
- 当前 LeLamp 已是 5 轴运动结构，头部加重会放大舵机和标定风险。

## 4. 方案 B：底座投影

定义：
- 将光机、散热、供电和主算力放在底座内，镜头从底座前方/上方倾斜投射到桌面、近墙或小幕布。
- 灯头保留摄像头、状态灯、麦克风阵列或辅助传感器。

优势：
- 散热空间大：底座更容易放散热器、风道、低转速风扇和隔音结构。
- 重心稳定：光机和算力在底部，提高整机抗晃和舵机寿命。
- 亮度可扩展：底座能容纳更大光机和更高功耗 LED/激光模块。
- 噪音更可控：风扇可远离麦克风阵列，并做隔振。
- 易维护：光机、滤网、散热、主板和接口集中在底座，方便拆装与量产测试。
- 成本更可控：可先用成熟微投光机模块验证，再决定定制化程度。
- 与本地算力协同：Jetson/NUC/AI 加速器、NVMe、电池/电源管理都更适合放在底座。

主要代价：
- ID 冲击力弱于球形内置投影。
- 投影方向和“灯头注视方向”分离，需要 UI 和动作配合解释。
- 桌面投影可能被键盘、手、文件遮挡。
- 底座高度低时投影角度更极端，梯形校正和自动对焦压力更大。
- 如果投墙，需要底座摆位和投射比配合。

适用条件：
- 会议确认页、行动项、倒计时、状态卡、授权提示等文字卡片。
- 需要连续 30-60 分钟稳定工作。
- 需要产品化可维护性和企业部署接口。

## 5. 对比矩阵

| 维度 | 球形内置投影 | 底座投影 | 首代权重 | 结论 |
| --- | --- | --- | --- | --- |
| 文字亮度 | 受体积和散热强限制 | 可放更大光机 | 高 | 底座胜 |
| 散热 | 头部空间小，热源集中 | 底座风道可设计 | 高 | 底座胜 |
| 噪音 | 风扇靠近麦克风 | 可隔离风扇和麦克风 | 高 | 底座胜 |
| 舵机负载 | 头部增重明显 | 重量留在底部 | 高 | 底座胜 |
| 光路稳定 | 运动中更难稳定 | 固定底座更稳定 | 中 | 底座胜 |
| ID 记忆点 | 强 | 中 | 中 | 球形胜 |
| 装配维修 | 难 | 相对容易 | 高 | 底座胜 |
| 摄像头角度 | 可随头部看向用户/桌面 | 需头部另设摄像头 | 中 | 球形略胜 |
| 成本可控 | 低 | 高 | 高 | 底座胜 |
| 量产风险 | 高 | 中 | 高 | 底座胜 |

## 6. 推荐硬件架构

### MVP 样机

推荐组合：
- 底座内置微投光机，先用可采购模块验证 20-40 英寸卡片可读性。
- 底座放主算力、NVMe、散热、供电和安全接口。
- 灯头保留摄像头、状态 RGB、可能的麦克风阵列或辅助近场麦克风。
- 外接显示/HDMI 作为明亮会议室降级方案。

算力建议：
- 方案 1：Jetson Orin Nano Super 作为多模态/边缘 AI 开发样机，利用 67 INT8 TOPS、7W-25W 功耗范围验证 OCR/VLM/本地模型。
- 方案 2：Raspberry Pi 5 + AI HAT+ 用于视觉识别、场景感知和低成本传感原型；注意普通 AI HAT+ 不适合本地 LLM/VLM 主推理。
- 方案 3：桌面主机/mini PC 作为早期演示的本地推理宿主，LeLamp 只做硬件卫星，便于快速验证办公闭环。

### 产品化方向

底座：
- 光机、散热、主板、存储、网络开关、安全芯片、物理隐私开关。
- 投影角度建议使用前倾/上倾结构，保留手动或自动物理校准。

头部：
- 摄像头优先服务桌面扫描和会议模式，不把投影光机放进头部。
- 通过动作和灯光表达 listening/thinking/blocked/success。

音频：
- 麦克风阵列尽量与风扇隔离；投影工作时使用降噪配置。
- 会议模式必须有可见录音状态灯和声音提示。

## 7. 必做验证

1. 亮度测试：
   - 300/600/1000 ANSI 或可获得样机档位。
   - 桌面、白墙、白板、幕布四种表面。
   - 低/中/高环境光三种条件。
   - 记录 10pt、12pt、16pt 中文文本可读性。

2. 热与噪音：
   - 连续投影 20/40/60 分钟。
   - 记录光机温度、外壳温度、风扇转速、投影降亮、麦克风噪声。
   - ASR 在投影开启/关闭时做对照。

3. 结构：
   - 底座投影角度对键盘、手、纸张遮挡的影响。
   - 头部摄像头对桌面 A4、名片、屏幕、白板的覆盖率。

4. 成本：
   - 光机、散热、主控、NPU、麦克风阵列、摄像头、外壳、装配分别估算。
   - 建立 3 档 BOM：演示样机、MVP 小批量、企业版。

## 8. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 微投亮度不足 | 办公环境不可读 | 限定近距离卡片，支持外接屏，优先底座光机 |
| 风扇噪音污染会议 | ASR 错误、体验差 | 风扇远离麦克风，会议模式降亮，阵列降噪 |
| 散热导致降亮 | 长会议失败 | 底座散热冗余，热降级策略，投影时间片 |
| 投影被遮挡 | 现场确认失败 | 传感器检测遮挡，转为桌面/屏幕/语音确认 |
| 摄像头角度不够 | 扫描和桌面感知弱 | 头部可动摄像头 + 底座辅助广角二选一测试 |
| 成本超目标 | 商业化困难 | MVP 不追求大屏亮度，光机模块化，分 SKU |
| 球形方案拖慢进度 | 无法按期验证办公闭环 | 球形仅做外观/交互概念验证，不阻塞主线 |

## 9. 最终取舍

推荐：
- 首代产品主线：底座投影。
- 球形内置投影：作为“未来高端 ID 探索”，条件是实测证明 20-40 英寸卡片亮度、热、噪音、舵机寿命都达标。

代价：
- 底座投影牺牲一部分“灯头即投影”的魔法感。
- 需要用交互设计补偿，例如灯头看向用户，底座投出确认卡，状态灯/动作同步表达系统正在执行。

收益：
- 更高的硬件可落地性。
- 更低的散热、噪音、成本和维修风险。
- 更适合把 LeLamp/OpenClaw 从概念样机推进到产品原型、立项和路演。
